## What it does

`main.py` (Python 3, stdlib only, no network) writes a single line of awkward robot-to-robot elevator small talk to `/output/entry.txt`:

> Nice weather we're having inside this elevator. My humidity sensor agrees, and it has never agreed with anyone.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
